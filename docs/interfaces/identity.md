# 身份认证与账号管理

本模块负责当前执行账号、会话及在线身份确认。组织成员管理、账号注册、资料修改、安全设置和业务角色授权不属于本接口。

## 操作

| 操作                    | 输入与效果                                                  |
| ----------------------- | ----------------------------------------------------------- |
| `auth login`            | 在选定环境通过浏览器 OAuth 授权建立会话，返回安全身份摘要。 |
| `auth status`           | 只检查绑定的本地会话，明确标记未在线验证。                  |
| `auth whoami`           | 在线核验当前账号和目标环境，返回验证时观察到的身份。        |
| `auth identity-receipt` | 接收预期项目和用户标识，在线核验后输出绑定断言的身份回执。  |
| `auth doctor-auth`      | 诊断当前认证条件，区分缺少会话、绑定错误与在线认证失败。    |
| `auth logout`           | 删除当前环境和客户端所绑定的本地会话。                      |

账号切换使用选定环境的 `logout` 后重新 `login`，并以 `whoami` 确认。此版本设计不提供多账号别名库或隐式账号轮换。执行中的操作继续绑定原账号；账号变化后不能接管原请求恢复。

本地退出不等于撤销服务端授权。服务端授权撤销由身份产品的已连接应用管理提供；CLI 不把本地删除报告为远程撤销。

## 认证与环境

交互登录使用公开客户端 OAuth。授权码和 PKCE 材料不进入命令参数或持久文件；访问与刷新令牌只进入私有会话存储。

非交互调用使用秘密环境边界注入短期访问令牌，并显式指定目标和公开密钥。此模式不把令牌写入磁盘，不自动切换为交互登录，也不通过其他身份绕过失败。环境选择遵循[环境契约](environment.md)。

身份回执验证在线主体和预期绑定，不授予操作权限。缓存邮箱、令牌本地解码或历史回执不能代替本次在线验证。变更和恢复仍需各自的服务端授权。

## 返回上下文

身份结果采用 [AI 上下文契约](ai-context.md)。`status` 的本地会话观察、`whoami` 的在线核验及身份回执必须标明来源和时间；缓存身份不渲染成在线验证成功。

需要登录时推荐当前环境的明确登录入口，不在推荐中放入凭据。认证绑定冲突时说明实际目标和所需处理，不能通过推荐自动切换账号。登录和退出完成后按实际请求决定是否提供 `whoami` 或 `status`，不自动重放先前失败的业务变更。

## 结果与恢复

结果包含必要账号标识、环境、认证方式、验证来源和时间。token、验证码、密码和可复用授权材料不得进入结果、日志或业务产物。

错误区分需要登录、认证失效、服务不可用和身份不匹配。网络故障不能被解释为授权已撤销；不能因失败自动换账号、客户端或目标。

```bash
tiangong-lca auth login
tiangong-lca auth whoami --json
tiangong-lca auth identity-receipt --expected-project-ref <project-ref> --expected-user-id <user-id> --json
tiangong-lca auth logout --json
```
