# CLI 回复模板

CLI 根据本次实际结果，在 `replyTemplate` 中返回一个 Markdown 文件路径。AI 只读取该文件，用真实业务结果组织简洁回复。

模板是表达指导，不是结构化输出协议。没有模板元数据对象、字段注册或占位符解析要求；业务事实继续由 CLI 结果提供。实现时模板随安装包分发，当前文档存在不表示已发布 CLI 已支持。

## 模板目录

| 结果                             | 表达指导                            |
| -------------------------------- | ----------------------------------- |
| 查询、列表、搜索、诊断或状态观察 | [查询与观察](query-result.md)       |
| 校验已经执行并得到结论           | [校验结果](validation-result.md)    |
| 操作范围或效果预览               | [操作预览](preview-result.md)       |
| 创建、保存、删除或本地处理完成   | [操作完成](operation-completed.md)  |
| 请求已受理，后续业务尚未完成     | [操作已受理](operation-accepted.md) |
| 需要补充输入或选择对象           | [需要决定](decision-required.md)    |
| 内容、版本或前置状态冲突         | [状态冲突](conflict-result.md)      |
| 声明的效果只完成部分             | [部分完成](partial-result.md)       |
| 派发后的实际效果无法确认         | [结果未知](outcome-unknown.md)      |
| 其他输入、认证、能力或业务失败   | [操作失败](command-failed.md)       |

多个命令可共用同一模板。状态未知或已产生部分效果时优先准确说明这些事实；不能用普通失败或需要决定掩盖。校验已执行但不通过仍使用校验模板，读取一页成功且有下一页仍使用查询模板。

## 共同表达要求

先说明本次结果，再保留足以识别的对象、状态、范围及下一步。根据当前问题压缩内容，不复制全部 JSON 或内部证据。

命令直接取自 `nextActions.command`，不猜测参数。只有说明没有命令时，讲清楚缺少的输入或选择；已有适用的用户决定直接复用。没有后续动作时结束回复。

已受理不能说成已完成，未检查不能说成通过，null 不能替换为零。模板缺失时按照实际结果回复并说明模板不可用，不重新执行操作。详细上下文规则见 [AI 上下文设计](../ai-context.md)。

Release 不纳入本轮模板改造。
