## W6a/A09 CLI schema disposition

This is an evidence ledger, not an approval to switch the CLI. The machine-readable report is [`tidas-spec-difference-ledger.json`](./tidas-spec-difference-ledger.json), generated by `scripts/ci/compare-tidas-spec.py` from one explicit `tidas-spec` source tree. It compares parsed JSON Schema structures and records every differing JSON pointer, category, and abbreviated value/hash. `oneOf`/`anyOf`/`allOf`, `required`, and `enum` are compared with stable identities or set semantics so taxonomy insertion does not create positional noise.

## Current qualified comparison

- CLI base: `f461a2244305cd2836a6e7fc3cab1d885167dfbd`.
- `tidas-spec` candidate: `6fb497bad562125ccc0c00a803351207b9ed438f`; package version `0.1.0`; manifest SHA-256 `fe82b77411e2a134469b206367556a52bf6be80419fcbc0749a2439dc785631b`.
- 18 files compared: 7 identical and 11 different.
- 110 differing semantic JSON locations are recorded. The differing files are `tidas_contacts.json`, `tidas_data_types.json`, `tidas_flowproperties.json`, `tidas_flows.json`, `tidas_flows_elementary_category.json`, `tidas_lciamethods.json`, `tidas_lifecyclemodels.json`, `tidas_locations_category.json`, `tidas_processes.json`, `tidas_sources.json`, and `tidas_unitgroups.json`.
- The report remains `unresolved`: no item is treated as a spec correction or CLI-local adapter until the spec/content owner and CLI owner record a decision with positive and negative fixtures.

Observed classes include dataset-version `$ref`/type changes, global-reference and classification structure changes, flow name requirements, numeric/reference constraints, LCIA normalisation and weighting types, lifecycle-model connection versions, source digital-file alternatives, and location/taxonomy membership. These labels describe the observed constraint locations; they do not decide which side is correct.

## Reproduction

From the CLI repository root:

```bash
python3 scripts/ci/test-compare-tidas-spec.py
python3 scripts/ci/compare-tidas-spec.py \
  --spec-root ../tidas-spec \
  --cli-commit f461a2244305cd2836a6e7fc3cab1d885167dfbd \
  --check docs/agents/tidas-spec-difference-ledger.json
```

The comparator fails if the selected source tree, file set, parsed content, or report metadata changes. A changed report requires re-running semantic review; it is not a reason to silently regenerate installed assets.

## W6b handoff gate

W6b may proceed only after every entry in the JSON report has an owner disposition, a constraint-level positive/negative fixture, and an independently reviewed compatibility decision. Until then, the existing CLI API, fallback path, installed directory, and published package remain the retained combination. No publication, production write, or root pointer update is implied by this ledger.
